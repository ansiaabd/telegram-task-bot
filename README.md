# TaskBot Calendar Sync

Telegram-бот для управления задачами с автоматической синхронизацией в календарь ПК (Outlook / Google Calendar).

## Проблема

В небольших командах и при личном использовании задачи часто теряются: ставятся в мессенджере, забываются в переписке, просрочиваются без напоминаний. Календарь живёт своей жизнью, а список дел — своей. Нет единой точки входа, которая связывала бы быстрый ввод задач (через Telegram) с отображением дедлайнов в календаре.

## Решение

Бот, который:
- принимает задачи через Telegram-команды (`/add`, `/list`, `/done`);
- хранит их в SQLite;
- автоматически создаёт события в календаре (Outlook или Google Calendar);
- напоминает о просрочках через APScheduler;
- синхронизирует статус: `/done` → пометка в календаре.

## Пользователи

- Фрилансеры и солопредприниматели, которые хотят вести задачи из телефона.
- Небольшие отделы (2–15 чел.), где нет места внедрению Jira / Trello.
- Все, кто устал дублировать дела в чатах и календаре вручную.

---

## Стек

- **Python 3.11** + `python-telegram-bot`
- **SQLite** (встроенная БД, не требует сервера)
- **APScheduler** (проверка дедлайнов)
- **Google Calendar API** / `pywin32` (для Outlook)

## Установка

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/annaabdu/telegram-task-bot.git
   cd telegram-task-bot
   ```

2. Создать виртуальное окружение:
   ```bash
   python3.11 -m venv venv
   source venv/bin/activate
   ```

3. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Настроить переменные окружения (см. ниже).

5. Запустить:
   ```bash
   python main.py
   ```

## Переменные окружения

| Переменная | Описание |
|------------|----------|
| `BOT_TOKEN` | Токен Telegram-бота (получить у @BotFather) |
| `CALENDAR_TYPE` | `google` или `outlook` |
| `GOOGLE_CREDS` | Путь к JSON-файлу учётных данных Google OAuth2 |
| `OUTLOOK_PROFILE` | Профиль Outlook (опционально) |

## Команды бота

- `/add <название> / <дедлайн> / <исполнитель>` — добавить задачу
- `/list` — показать все активные задачи
- `/done <id>` — отметить задачу выполненной
- `/delete <id>` — удалить задачу
- `/help` — справка
