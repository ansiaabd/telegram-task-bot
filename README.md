# TaskBot — менеджер задач через Telegram

Telegram-бот для управления задачами с ролевой моделью (админ, модератор, пользователь), подтверждением выполнения и уведомлениями о просрочках.

---

## Возможности

- **Ролевая модель** — админ, модератор, пользователь. Модератор создаёт задачи и подтверждает выполнение
- **Регистрация** — каждый участник пишет `/start`, бот сохраняет его и может присылать уведомления
- **Создание задач** — через `/add` (пошагово, с выбором исполнителя из списка) или одной строкой
- **Inline-формат** — `задача / title / deadline / @user` или `задача title / deadline / @user`
- **Умный парсинг дат** — понимает «8 июня в 12», «завтра в 15», «сегодня в 20», «08.06 18:00»
- **Выбор исполнителя** — inline-кнопки со всеми пользователями, включая себя
- **Личный список** — `/list` показывает задачи в зависимости от роли
- **Напоминания** — каждую минуту проверяет дедлайны, уведомляет администратора и исполнителя
- **Подтверждение выполнения** — исполнитель пишет «выполнено» → создатель задачи или админ подтверждает
- **Inline-кнопки** — быстрые действия: ✅ Выполнено, 🗑 Удалить, ✅ Подтвердить, ❌ Отклонить

## Команды

### Для всех

| Команда | Описание |
|---------|----------|
| `/start` | Зарегистрироваться в системе |
| `/add` | Создать задачу (пошагово) |
| `задача / title / deadline / @user` | Создать задачу одной строкой |
| `/list` | Мои активные задачи |
| `/done <id>` | Отметить задачу выполненной |
| `/delete <id>` | Удалить задачу |
| `/overdue` | Просроченные задачи |
| `/cancel` | Отменить создание задачи |
| `/help` | Справка |
| Написать «выполнено» / «сделано» / «готово» | Быстрая отметка задачи |

### Для администратора

| Команда | Описание |
|---------|----------|
| `/list all` | Все активные задачи |
| `/pending` | Задачи на подтверждении |
| `/users` | Список пользователей с ролями |
| `/removeuser <id>` | Удалить пользователя |
| `/promote <id>` | Назначить модератором |
| `/demote <id>` | Снять модератора |

---

## Роли

| Роль | Видит задачи | Может подтверждать |
|------|-------------|-------------------|
| 👑 **Админ** | Все | Любые |
| 🛡 **Модератор** | Назначенные ему + созданные им | Только свои |
| 👤 **Пользователь** | Только свои | — (только отмечать done) |

---

## Форматы даты

| Ввод | Результат |
|------|-----------|
| `8 июня в 12` | 2026-06-08 12:00 |
| `завтра в 15` | завтра 15:00 |
| `сегодня в 20` | сегодня 20:00 |
| `08.06 18:30` | 8 июня 18:30 |
| `в 14 часов` | сегодня 14:00 |
| `12:30` | сегодня 12:30 |

## Пример работы

```
Пользователь:   /start
Бот:           👋 Привет, fantake! Ты зарегистрирован...

Админ:         /promote 12345
Бот:           ✅ Пользователь 12345 назначен модератором

Модератор:     /add
Бот:           👤 Выберите исполнителя: [Себя] [@ivan] [@petr]

Модератор:     (выбирает @ivan)
Бот:           ✅ Исполнитель: @ivan
               📝 Введите название задачи:

Модератор:     Проверить отчёт / 8 июня в 18
Бот:           ✅ Задача #1 добавлена: Проверить отчёт
               ⏰ 8 июня 2026 в 18:00 | 👤 @ivan

@ivan:         выполнено
Бот модератору: 📬 Исполнитель отметил задачу #1...
                 [✅ Подтвердить] [❌ Отклонить]

Модератор:     нажимает ✅ Подтвердить
Бот @ivan:     ✅ Администратор подтвердил выполнение задачи #1
```

## Установка

```bash
git clone https://github.com/ansiaabd/telegram-task-bot.git
cd telegram-task-bot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Создать `.env`:
```
BOT_TOKEN=токен_от_@BotFather
ADMIN_ID=ваш_telegram_id
```

Запуск:
```bash
python main.py
```
