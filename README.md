# TaskBot — менеджер задач через Telegram

Telegram-бот для управления задачами в небольшой команде. Исполнители регистрируются через `/start`, получают уведомления о новых задачах и просрочках. Подтверждение выполнения — через администратора.

---

## Возможности

- **Регистрация** — каждый участник пишет `/start`, бот сохраняет его и может присылать уведомления
- **Создание задач** — через `/add` (пошагово) или одной строкой: `задача / title / deadline / assignee`
- **Умный парсинг дат** — понимает «8 июня в 12», «завтра в 15», «сегодня в 20», «08.06 18:00»
- **Личный список** — `/list` показывает только задачи пользователя; админ видит все (`/list all`)
- **Напоминания** — каждую минуту проверяет дедлайны, уведомляет админа и исполнителя
- **Подтверждение выполнения** — исполнитель пишет «выполнено» / «сделано» / «готово» → админ подтверждает
- **Управление пользователями** — `/users`, `/removeuser <id>` (админ)
- **Inline-кнопки** — быстрые действия: ✅ Выполнено, 🗑 Удалить

---

## Команды

### Для всех

| Команда | Описание |
|---------|----------|
| `/start` | Зарегистрироваться в системе |
| `/add` | Создать задачу (пошагово) |
| `задача / title / deadline / @user` | Создать задачу одной строкой |
| `/list` | Мои активные задачи |
| `/done <id>` | Отметить задачу выполненной |
| `/overdue` | Просроченные задачи |
| `/cancel` | Отменить создание задачи |
| Написать «выполнено» | Быстрая отметка задачи |

### Для администратора

| Команда | Описание |
|---------|----------|
| `/list all` | Все активные задачи |
| `/pending` | Задачи на подтверждении |
| `/users` | Список зарегистрированных пользователей |
| `/removeuser <id>` | Удалить пользователя |

## Форматы даты

| Ввод | Результат |
|------|-----------|
| `8 июня в 12` | 2026-06-08 12:00 |
| `завтра в 15` | завтра 15:00 |
| `сегодня в 20` | сегодня 20:00 |
| `08.06 18:30` | 8 июня 18:30 |
| `в 14 часов` | сегодня 14:00 |
| `12:30` | сегодня 12:30 |

## Пример работы

```
Пользователь:   /start
Бот:           👋 Привет! Ты зарегистрирован...

Админ:         задача / Проверить отчёт / 8 июня в 18 / @ivan
Бот:           ✅ Задача #1 добавлена... (уведомление @ivan)

@ivan:         выполнено
Бот админу:    📬 Исполнитель отметил задачу #1...
               [✅ Подтвердить] [❌ Отклонить]

Админ:         нажимает ✅ Подтвердить
Бот @ivan:     ✅ Администратор подтвердил выполнение задачи #1
```

## Установка

```bash
git clone https://github.com/ansiaabd/telegram-task-bot.git
cd telegram-task-bot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Создать `.env`:
```
BOT_TOKEN=токен_от_@BotFather
ADMIN_ID=ваш_telegram_id
```

Запуск:
```bash
python main.py
```
